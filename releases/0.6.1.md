## Playback and library polish

- Move the now-playing heart beside the quality label above the waveform.
- Use compact quality labels with the active decoder's input format, bit depth and sample rate. Plex transcodes update the badge without borrowing the original file's precision, and Track information distinguishes the file from the playing format.
- Share track rows across playlists, Liked Songs, albums and artists. Queue and Radio stay under the track details; the heart sits beside the rating. Liked hearts and ratings remain visible without hovering.
- Enable the combined Rating & like column by default, with a persistent visibility toggle.
- Keep duration columns and virtual-list scrollbar geometry stable during hover and unloaded-page jumps.
- Fit the first window to the display's usable work area, preserving usable saved window sizes and positions.

## In-app update repair

- Grant the separate native download and install operations used by Hibiki's updater, preserving the download → save playback/preferences → install sequence.
- Update capability regression coverage to exercise that exact sequence and keep unused native operations denied.

**One-time manual update:** Hibiki 0.6.0 and earlier cannot grant these missing permissions to themselves. Download and install the appropriate package from this release, with existing Hibiki copies fully closed. Settings, liked songs, playlists and saved music remain in their existing locations. Subsequent in-app updates can use the repaired permissions.
