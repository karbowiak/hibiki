## In-app update repair

- Grant the separate native download and install operations used by Hibiki's updater, preserving the download → save playback/preferences → install sequence.
- Update capability regression coverage to exercise that exact sequence and keep unused native operations denied.

**One-time manual update:** Hibiki 0.6.0 and earlier cannot grant these missing permissions to themselves. Download and install the appropriate package from this release, with existing Hibiki copies fully closed. Settings, liked songs, playlists and saved music remain in their existing locations. Subsequent in-app updates can use the repaired permissions.
