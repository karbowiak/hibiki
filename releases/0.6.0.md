## A new look for Hibiki

Artwork now carries through the window, with sharp artist/album heroes, a blurred
continuation, translucent navigation and colors drawn from the active image.
Playback controls keep their own now-playing palette. Browsing pages can rotate
backgrounds, and cards, loading states, search and contextual actions share the
same visual language.

## Metadata and playlists

- Redesigned artist/album/playlist editors with reviewed Plex saves, editable
  tags and locks, separate posters/backgrounds and artwork uploads.
- Canonical MusicBrainz/Heya identity review and optional explicit Heya discovery.
- SoulSync album/track enrichment and optional premium TheAudioDB metadata/artwork.
- Playlist-level sync controls with manual Plex → ListenBrainz as the default,
  optional two-way sync, and one ListenBrainz browser for owned, generated and
  collaborative playlists.
- Create Sync immediately creates a local playlist and matches songs in the
  background. Matching handles credits, punctuation and equivalent library
  copies; unresolved songs remain available for later review.
- Stable Weekly Exploration and Weekly Jams channels follow new editions into
  the same local playlists while Hibiki is open or on next launch. Edition dates
  appear in descriptions.
- Ordered verification, conflict review and durable recovery prevent duplicate
  creation and blind retries. Unsupported repeated Plex occurrences remain in
  review while other reliable matches can be imported.

## Reliability and packaging

- Account-scoped saved-library browsing for visited pages; offline browsing is
  read-only and does not provide cached-audio playback.
- Non-destructive album/media-version comparison and current Plex track refetch
  before playback of sanitized cached metadata.
- Correct Plex library identity and current poster-inventory parsing, including
  local artwork previews. Playlist creation uses the correct ordered track URI
  and makes a single request.
- Search text is correctly URL-encoded, and verified playlist updates refresh
  the affected page without leaving an empty cached result behind.
- AppStream metadata, refreshed interface previews and verified AppImageUpdate
  `.zsync` companions alongside signed Tauri updater artifacts.
- Verified macOS disk images and signatures for all nine installers, with
  signed release-version checks in the publication gate and application updater.

Existing appearance and playback settings are retained. Optional metadata
services require configuration, and linked sync requires explicit setup. AI
features are deferred; this release does not install or download a local model.
